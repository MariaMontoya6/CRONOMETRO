# ¿How to install Icarus and Gtkwave?

To use these programs, you can integrate them with VS Code. You will find two tutorials: the first one is for downloading VS Code and MSYS2 (a software distribution and building platform for Windows), MSYS2
 will help you compile the C code used for the testbench. The second tutorial is for downloading Icarus Verilog and GTKWave, and it also includes some examples for creating testbenches.

 [First video](https://youtu.be/-gLsB2ZZXLs?si=5M_Fa8p4zbvULqGZ)

 [Second video](https://youtu.be/08S6NxUs-Uo?si=NLF2jW3uXT-VEfDV)

Additionally, for creating testbenches you also can use Verilator, which allows you to handle large testbenches.

[Download verilator](https://youtu.be/ALuaCai1W_0?si=w3bq70KpKdJi_dg3)

These option (Icarus and verilator) are excellent open source tools, so you can use it for your own projects or student projects because Icarus and Verilator have limited compliance with IEEE 1364 and IEEE 1800 (Verilog and system verilog standards)

## ¿How to do a testbench?

Testbenches consist of non-synthesizable verilog code which generates inputs to the design and checks that the outputs are correct.Below you will find a guide.
